Leagues & Drafts

Same structure you know from major fantasy platforms. Pick your sport above, then choose how you want to play.

🌍

Public League

Join an open league. Spots fill first-come. Live draft with other managers.

  • 8–12 teams
  • Snake or auction
  • Standard scoring
🔐

Private League

Create a league code and send it to your friends. Everyone uses the same link and settings.

  • Custom team count
  • Shareable invite code
  • Easy friend setup
🤖

vs CPUs

Draft against computer managers. Ideal for practice or solo seasons.

  • Multiple difficulties
  • Instant start
  • No waiting on humans
📋

Mock Draft

Full practice draft. Reset as many times as you want. Zero consequences.

  • Any team count
  • Live board + timer
  • Unlimited do-overs
